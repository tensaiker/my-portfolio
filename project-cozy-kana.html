Project Overview

A tactile, gamified Japanese language learning mobile application built with Flutter and Dart, designed to guide beginners through mastering Hiragana and Katakana. Inspired by a cozy pastel stationery aesthetic, the app bridges stroke-by-stroke handwriting practice, spaced repetition (SRS) flashcards, dynamic vocabulary building, and reactive mastery tracking into an interactive learning journey.

Technical Challenges
  • Dynamic Prerequisite Unlocking & State Synchronization: Designing a unified state management architecture (ProgressService with ListenableBuilder) so that completing writing lessons or quizzes reactively updates row locks, streak flames, weekly calendars, and flashcard availability across multiple tabs without UI lag or manual page reloads.
  • Constrained Syllable & Word Filtering: Implementing an algorithm in VocabularyService that filters hundreds of vocabulary words dynamically, ensuring learners are only quizzed on words composed purely of characters they have already unlocked in previous lessons.
  • Multi-Stage Handwriting Tracing: Accurately resolving custom vector stroke paths and Unicode character variants (base, dakuon, handakuon, and small subscript yoon/sokuon) on a raw 2D canvas with real-time accuracy scoring.
  • Consistent Offline Audio Delivery: Integrating native Text-to-Speech (flutter_tts) while maintaining user-configured speech rates, volume levels, and master sound toggles across disparate modes (quizzes, flashcard flips, vocabulary dictionary, and writing prompts).
Key Features
  • Sequential Lesson Progression: Structured unlocking system spanning Basic Kana, Dakuon, and Yoon contracted sounds, complete with celebration animations when clearing milestones.
  • Interactive Stroke Tracing: Real-time canvas for tracing kana characters with stroke order animations, vector path validation, and accuracy grading.
  • SRS Flashcards & Difficulty Integration: 3D perspective flippable flashcards with 4-stage recall ratings (Again, Hard, Good, Easy) that tag characters directly for tailored quiz sessions.
  • Dynamic Word Builder Mini-Game: Interactive syllable-tile assembly game with hints, instant TTS audio pronunciation, and difficulty adjustments based on unlocked kana.
  • Offline Vocabulary Library: Searchable Japanese word bank with English definitions, syllable breakdowns, and locked-word prerequisite prompts.
  • Tactile 3D Stationery UI: Custom design system featuring warm pastel cream/beige tones, mechanical button click depths, drop-shadow elevations, and haptic feedback.
  • Developer & Debug Toolkit: Built-in dev panel in settings to simulate SRS ratings, toggle instant unlocks, and reset row checkpoints for live QA testing.
What I Have Learned
  • Reactive State Architecture: Implementing decoupled, persistent state management in Flutter using ListenableBuilder and SharedPreferences without introducing unnecessary third-party overhead.
  • Advanced Custom Canvas & Animations: Managing touch input streams, vector interpolation, and custom matrix transformations (Matrix4 3D perspective flips and tactile button presses).
  • Gamified Educational UX: Designing intrinsic motivation loops (daily streak counters, weekly activity dot matrices, and mastery percentages) to prevent cognitive overload in language acquisition.
  • Clean Code & Service Layering: Structuring an extensible codebase with dedicated service singletons (ProgressService, VocabularyService, TactileFeedback) to cleanly separate domain data from UI screens.
